GradPath Atlas — Demo how-to

MKTG 4150 Team Assignment 1 · A 3-minute walkthrough of the deployed web app

Live app: https://marthaweisbender-cpu.github.io/gradpath-atlas/
Repository: https://github.com/marthaweisbender-cpu/gradpath-atlas
Best viewed: desktop browser, window ≥ 1280 px wide (the app is desktop-first by design).

GradPath Atlas is a static single-page app hosted on GitHub Pages. There is no server account to log into: every visitor gets a private workspace stored in their own browser, pre-seeded with fictional demo data. All universities, programmes and people are fictional.

Demo script

  1. Landing page → click Start planning — free. Sign up with any email and a password of 8+ characters (e.g. demo@example.test / password123) and tick the data notice.
  2. Dashboard opens with six fictional programmes: readiness bars, next deadlines with date tiles, and the list of missing documents.
  3. Compare (sidebar) → sort by Deadline or Tuition, filter by Status, toggle columns. This is the core comparison matrix.
  4. Click MSc Marketing Analytics → change its status, link a document to a requirement, add a note. Readiness updates immediately.
  5. Tasks → Submit Port Meridian application stays locked until Request reference from Dr. Okafor is ticked: task dependencies.
  6. Documents → set Personal statement — product track to ready; the reuse matrix and the dashboard update.
  7. Pricing (top-right link on the landing page, or Settings → Change plan) → Upgrade (test) on Application Pass. A test-mode banner appears and the free-plan limit of three programmes is lifted. No payment is taken.
  8. Adviser review → Export CSV or Print / PDF for the read-only summary.
  9. Settings → Reset demo data restores the seed between demos; Erase everything wipes the account to show sign-up again.
